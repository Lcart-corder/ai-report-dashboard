# やとアカ運営AI-PMOシステム 設計ドキュメント

やとアカの理事・スタッフ・行政関係者が、部活動の地域展開に関するプロジェクト・会議・タスクを一元管理するための、AI支援型 PMO（Project Management Office）システムの設計ドキュメント一式です。

- **対象組織**: やとアカ
- **先行導入対象**: イベント部会
- **初期構成**: Google Apps Script Webアプリ ＋ Googleスプレッドシート ＋ Google Drive／ドキュメント／カレンダー
- **AIの位置づけ**: 業務の自動実行はせず、会議準備・議事録整理・タスク抽出・進捗分析・リマインド案・次回アジェンダ案の作成を支援する

## 試作版アプリ（実装）

モックアップ（画面1〜10）を実際に動作する Web アプリとして実装した試作版が [`app/`](app) にあります（Next.js + TypeScript + Tailwind、サンプルデータ動作）。

```bash
cd app && npm install && npm run dev   # http://localhost:3000
```

詳細は [`app/README.md`](app/README.md) を参照してください。

## バックエンド（GAS + スプレッドシート）

要件定義書 9.1 の初期構成に沿った Google Apps Script Web App バックエンドを [`gas/`](gas) に実装しています（スプレッドシートをDBとする列名ベースの REST 風 CRUD API）。フロントは `NEXT_PUBLIC_GAS_URL` を設定するとこの API と同期して動作します（未設定時はローカルの localStorage モード）。構築・デプロイ手順は [`gas/README.md`](gas/README.md) を参照してください。
