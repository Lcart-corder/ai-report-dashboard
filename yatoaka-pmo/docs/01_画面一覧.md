# やとアカ運営AI-PMOシステム 画面一覧

- **対象版数**: 第0.1版準拠
- **前提**: 初期構成は Google Apps Script Webアプリ（SPA的な単一Webアプリ内での画面切替）+ Googleスプレッドシートをデータベースとする
- **原則**: レスポンシブWebデザイン（PC＝左メニュー、スマートフォン＝下部固定メニュー）で同一画面を共有する

---

## 1．画面ID体系

画面IDは `S` + 分類2桁 + 連番2桁 で管理する。

| 分類 | 範囲 | 内容 |
| --- | --- | --- |
| 共通・認証 | S00xx | ログイン、ホーム、通知、設定 |
| ダッシュボード | S01xx | 個人／部会／組織全体 |
| プロジェクト | S02xx | 一覧・詳細・編集 |
| タスク・WBS | S03xx | WBS・タスク一覧・詳細 |
| カレンダー | S04xx | カレンダー各表示 |
| 会議 | S05xx | 会議・議事録・アジェンダ |
| 部会 | S06xx | 部会管理 |
| ステークホルダー | S07xx | 関係者管理 |
| 資料・ナレッジ | S08xx | 資料一覧・組織基準文書 |
| KPI | S09xx | KPI管理 |
| AI支援 | S10xx | 今日の提案・ChatGPT出力 |
| 管理・設定 | S11xx | ユーザー・権限・マスタ |

## 3．メニュー構成と画面の対応

| メニュー | 遷移先画面 |
| --- | --- |
| ダッシュボード | S0101 / S0102 / S0103 |

| カレンダー | S0401 / S0402 / S0403 |

| 部会 | S0601 → S0602 |
| ステークホルダー | S0701 → S0702 |
| 資料 | S0801 / S0803 |
| KPI | S0901 |
| AI支援 | S1001 / S1002 / S1003 / S1004 |
| 設定 | S1101 / S1102 / S1103 / S1104 |

### 3.2 スマートフォン（下部固定メニュー）

| メニュー | 遷移先画面 | 補足 |
| --- | --- | --- |
| ホーム | S0002 | 今日やること中心 |
| タスク | S0303 → S0304 / S0306 | 片手操作でクイック更新 |
| 会議 | S0501 → S0502 / S0505 | 議事メモ・予定確認 |
| 資料 | S0801 → S0802 | Driveリンク参照 |
| その他 | S0101 / S0102 / S0701 / S1001 / S1002 / S1101 | メニュー集約 |

「頻繁に使うボタン（タスク完了・進捗更新・追加）」はスマートフォンでは画面下部に固定する。
