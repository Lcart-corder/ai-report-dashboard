# やとみ放課後アカデミー 予算・実績・精算ブック（実装）

要件定義書 [`docs/yatomi-academy-requirements.md`](../docs/yatomi-academy-requirements.md) の
§11（スプレッドシート構成）・§17（様式一覧）・§18（計算式）を、
Google Apps Script で**そのまま生成できる形**に実装したもの。

## 中身

| ファイル | 役割 |
|---|---|
| `gas/setup_academy.gs` | `setupAcademyBook()` を実行すると13シート＋名前付き範囲＋計算式を自動生成 |
| `gas/appsscript.json` | GASマニフェスト（タイムゾーン Asia/Tokyo） |

## 生成される13シート

| シート | 内容 | 主な自動計算 |
|---|---|---|
| 00_入力条件 | 全前提値。名前付き範囲を定義 | 参加者1人あたり単価 |
| 01_収入シミュレーション | 100〜300人の歳入 | `単価×参加者数`／歳入計 |
| 02_支出シミュレーション | **指導員謝金3案(4列)** ＋ 費目別 | `SUMIF`で直接16,039,600・間接744,800・諸経費4,811,880・総事業費21,596,280 |
| 03_収支サマリー | 歳入・歳出・収支・**返還見込** | 参加者数連動 |
| 04_指導員配置 | 15種目の謝金・研修ステータス | 種目謝金504,000×15＝7,560,000／追加判定 |
| 05_参加者管理 | 台帳＋集計 | `COUNTIF`（LINE登録・未払） |
| 06_活動日報 | 実施記録 | 欠席・稼働時間の自動算出 |
| 07_月次実績 | 月次報告 | `SUMIFS/COUNTIFS`で日報から集計 |
| 08_補助対象経費 | 02から自動抽出 | `FILTER`＋`SUMIF("補助*")` |
| 09_補助対象外経費 | 02から自動抽出 | `FILTER`＋`SUMIF("*対象外*")` |
| 10_協賛管理 | 協賛台帳＋シミュレーション | 区分別小計 |
| 11_請求入金管理 | 請求・消込 | 未収差額 |
| 12_年度末精算 | 予算/実績/差額・返還 | 証憑チェックリスト |
| 13_行政提出様式出力 | 別添1-2（提出=A/B案の謝金） | 実支給との差額 |
| 14_収支予算書 | 会計要項形式（収入の部／支出の部：事業費・管理費） | `SUMIF(会計区分)`で人件費/その他/管理費を集計、当期収支差額・返還後 |
| 15_中期収支計画 | 成長カーブ（年度別参加者・協賛を入力） | 年度別の収入計/支出計/当期/返還後/返還後累計 |

## 使い方

1. Googleスプレッドシートを新規作成
2. **拡張機能 → Apps Script**
3. `gas/setup_academy.gs` の内容を貼り付けて保存
4. 関数 `setupAcademyBook` を選び ▶実行（初回のみ権限承認）
5. 完了。`00_入力条件` を編集すると全シートが連動

> 別ブックを対象にする場合は、スクリプト冒頭の `ACADEMY_SS_ID` にブックIDを設定。

## 設計上のポイント（要件定義書との対応）

- **指導員謝金3案を統一しない**（§1）：`00_入力条件` の `採用案(A/B/C)` で切替。
  02の3案ブロックが `A=5,760,000 / B=6,720,000 / C=7,560,000` と差額 `C−A=1,800,000` を常時表示。
- **提出用と実運営を分離**（§13）：`提出案(A/B)` で別添1-2（13）を補助基準額で出力しつつ、
  02/03は実支給Cで管理。両者の差額を明示。
- **数値は資料実数で検算済み**：直接16,039,600・間接744,800・諸経費4,811,880・
  総事業費21,596,280・歳入(200人)24,272,480 が計算式で一致。
- **返還ロジック**（§12）：参加者連動収入を返還見込として03/12に計上。

## 未確定（要件定義書 §16 の確認事項に連動）

管理者報酬の日数・単価、参加費の月数（7/12）、返還額の算式、期末手当・専門家費用の
補助区分などは資料間で差異があるため、`00_入力条件`・02のメモ行で切替/注記できるようにしてある。
確定後に値を差し替える。
