# やとみ放課後アカデミー プロジェクト バージョン履歴

本セッションで作成した成果物のコミット履歴。各行のコミットハッシュで、いつでもその時点の状態に戻せる。

**復元方法（例）**：
```bash
# 特定バージョンのファイルだけを取り出す
git show <hash>:yatomi-academy/preview.html > yatomi-academy/preview.html

# その時点のブランチ全体に戻す（以降の変更は失われるので注意）
git reset --hard <hash>
```
